## Hi, I'm Ismail Alshofi

AI engineer. I work on the parts that sit between the model and the user: streaming, orchestration, memory, retrieval and evaluation. Mostly agentic and real-time voice systems.

I started as a Flutter developer, then moved to machine learning and computer vision research at Damascus University, and now I build production voice agents and LLM systems.

I like to start with a question and end with a number.

**Portfolio:** [ismail-alshofi.vercel.app](https://ismail-alshofi.vercel.app)
